# Область гистерезиса метастабильного режима при повторных запросах

Воспроизводимое имитационное исследование: как политика повторов (нет / фиксированная / экспоненциальная выдержка с джиттером / с бюджетом), дисциплина очереди (FIFO / LIFO / адаптивный LIFO), передача крайнего срока и распределение времени обслуживания влияют на ширину области бистабильности Δ = ρ_fold − ρ_release в модели одного сервиса с очередью и повторными запросами.

## Содержимое
- `src/` — дискретно-событийный симулятор (heapq), протоколы A (рост нагрузки) и B (снижение после перегрузки), метрики.
- `docs/MODEL_SPEC.md` — спецификация модели и протоколов; `docs/THEORY.md` — аналитические формулы и mean-field модель; `docs/PREREGISTRATION.md` — гипотезы и план анализа, зафиксированные до основного прогона (тег `prereg-v1`).
- `tests/` — тесты; `reports/validation.md` — проверка симулятора по аналитическим результатам.
- `experiments/` — сетки конфигураций и запуск (возобновляемый, параллельный); `results/` — сырые данные и таблицы.
- `analysis/` — скрипты анализа; `figures/` — графики (png, svg, данные в csv).

## Установка и воспроизведение
```
python -m venv .venv
.venv/bin/pip install -r requirements.lock      # Windows: .venv\Scripts\pip
bash reproduce.sh                               # Windows: ./reproduce.ps1
```
Скрипт воссоздаёт таблицы (`results/analysis/`) и графики (`figures/`) из сырых данных основного прогона (`results/raw/`, seed ≥ 1 000 000). Данные pilot (seed < 1 000 000) использовались только для подбора параметров и в основной анализ не входят.

## Данные
Сырые данные (parquet: `results/raw/` — основной прогон, 379 984 задачи; `results/explor/` — эксплораторные дозапуски; `results/pilot/` — подбор параметров) в репозиторий не входят из-за размера и лежат в архиве Zenodo: https://doi.org/10.5281/zenodo.23763646. Распакуйте архив в корень репозитория так, чтобы появились файлы `results/raw/part-*.parquet`, затем запустите `reproduce.sh`.
