# Пакет результатов (единственный источник чисел для статьи)

Правило: числа в статье берутся только отсюда или из перечисленных таблиц и файлов. Подтверждающий анализ: reports/analysis.md (тег препрегистрации prereg-v1); дополнения: reports/analysis_addendum.md (диагностики), reports/analysis_explor.md (дозапуски по горизонту, триггеру, параметрам); критика: внутренней проверки. Таблицы с источниками-csv: reports/analysis_tables.md. Воспроизведение: reproduce.sh / reproduce.ps1 (сырые данные results/raw, seed ≥ 1 000 000, 379 984 прогона; эксплораторные results/explor, 75 440 прогонов).

## 1. Модель и протокол (кратко, для раздела «Метод»)
Один сервис, c = 8 воркеров, очередь K = 128, таймаут T = 10, время в единицах E[S] = 1. Политики повторов R0–R3, дисциплины FIFO, LIFO, ALIFO (θ_q = 0,5), передача срока D off/on, обслуживание Exp, LogN (cv = 2), Pareto (α = 2,5) — 72 конфигурации. Протокол A (здоровый старт, всплеск нагрузки m_s = 1,5 на D_s = 25, шаг ρ) даёт ρ_fold; протокол B (перегрузка ρ = 1,05 длиной 1000, затем снижение) даёт ρ_release; Δ = ρ_fold − ρ_release. Отказ: g_final < θ = 0,5 в окне 300; горизонт восстановления H_rec = 1500. Параметры зафиксированы препрегистрацией (docs/PREREGISTRATION.md); отклонения перечислены в её разделе «Отклонения».

## 2. Что можно утверждать (с источником)
1. **Метастабильность с гистерезисом есть только у R1 и R2 при FIFO.** N1 = 12 из 72, N2 = 10 (табл. A1, A3; results/analysis/t01_thresholds72.csv, t30_classification.csv). У LIFO, ALIFO (48 конфигураций), R0 и R3 гистерезиса при ρ ≤ 1 нет; R3/FIFO/off срывается при ρ ≈ 0,96 без удержания (табл. A2). Для 56 конфигураций оба порога цензурированы на 1,0, Δ = 0 по соглашению.
2. **Отрицательный результат устойчив к триггеру и параметрам** (эксплораторно): сильные триггеры (3; 50), (4; 100) не создают гистерезиса у LIFO, ALIFO, R3 (reports/analysis_explor.md § 2); бюджет R3 0,05–0,20 и паузы R2 0,5–2,0 выводов не меняют (§ 3). Формулировать «в данной модели и параметрах».
3. **Контроль R0:** Δ от 0,000 до 0,0009 при ρ ≤ 1, нижняя граница ДИ нигде не выше 0 (табл. A4); оговорка — R0 срывается сам при ρ = 1,0, контроль слабый.
4. **Передача срока сокращает область, и сильнее при тяжёлом хвосте (H1′, подтверждающая):** r = Δ_on/Δ_off: Exp 0,538, LogN 0,205, Pareto 0,804; r(Exp) − r(LogN) = 0,333 [0,320; 0,346] (табл. H1′). Оговорка: при определении отказа без θ разность 0,300 [0,287; 0,314]; при θ = 0,3 у LogN при D = on Δ = 0, то есть передача срока снимает область полностью, а r(Exp) падает до 0,323 (reports/analysis_addendum.md); знак эффекта сохраняется. Для D = on режим отказа лежит около g ≈ 0,2–0,6, поэтому Δ зависит от θ.
5. **R3 против R2 (H2′):** внутри FIFO R3 снижает потерю goodput L_A на 0,1116 [0,1085; 0,1149]; внутри ALIFO эффект +0,0005 (на полу L_A ≈ 0,003, не значим практически) (табл. H2′). Формулировка H2 (комбинация R3+ALIFO сильнее каждой меры) по Δ непроверяема (Δ ≥ 0), по L_A не подтверждается.
6. **R2 ≈ R1:** R2 − R1 по Δ = +0,011 [0,008; 0,014], значим только при D = on (≈ +0,023); эффект сопоставим с разбросом методов оценки порога (до 0,015–0,017), в двух ячейках при D = on разность достигает +0,028, поэтому писать «порядка 0,01–0,03 и только при D = on».
7. **Mean-field занижает ρ_release** (R1, FIFO, off, Exp): отклонение +0,056 [0,053; 0,058] при H_rec = 1500, +0,074 при 3000, +0,091 при 6000 — критерий ≤ 0,10 выполнен (H3); ρ_fold симуляции ниже mean-field на 0,062 (H3b не отвергнута).
8. **Δ зависит от горизонта (эксплораторно, важно):** ρ_release растёт логарифмически с H_rec (0,335 → 0,400 при 1500 → 24000, +0,0162 [0,0150; 0,0175] за удвоение), Δ для R1/FIFO/off/Exp падает с 0,528 до 0,457, для R1/FIFO/on/LogN окно закрывается при H ≳ 10⁴; отклонение от mean-field 0,107 и 0,123 при 12000 и 24000 превышает 0,10 (reports/analysis_explor.md § 1). Поэтому описывать как «область гистерезиса конечного горизонта H», с таблицей Δ(H), а не как бистабильность в пределе.
9. **Чувствительность:** при T = 20 и K = 64 метастабильности нет; m_s = 1,25 и 1,75 дают Δ = 0,587 и 0,443 (база 0,528); длина перегрузки B (400/1000/2000) сдвигает ρ_release не более чем на 0,012 (reports/analysis.md § 5, analysis_explor.md § 4).

## 3. Что нельзя утверждать
- Что Δ — универсальная метрика сравнения политик и дисциплин: у 60 из 72 конфигураций Δ = 0 (у 56 по цензуре); сравнение дисциплин вне FIFO возможно только по непрерывным метрикам (L_A и др., эксплораторно).
- Что LIFO/ALIFO/бюджет «устраняют метастабильность» вообще: это результат одной синтетической модели одного сервиса; эффект LIFO при перегрузке известен из литературы (docs/NOVELTY.md).
- Что Δ_ext (область ρ > 1) что-либо показывает: исследовательская величина, протокол B при ρ > 1 не снижает нагрузку.
- Что H1 (по буквальной формулировке) подтверждена или отвергнута: τ-b = 0,973 получено из 14 вырожденных ячеек из 18; вердикт зависит от выбора ДИ (по ячейкам 0,884 — формально «отвергнута», по репликам 0,627 — нет).
- Что «H3 подтверждена» вообще: только для H_rec ≤ 6000.
- Что результаты переносятся на реальные системы: параметры синтетические; времена E[S] = 1 условны.
- Что ДИ учитывают модельную неопределённость: они отражают только выборочную ошибку.

## 5. Ограничения (для раздела «Ограничения»)
Двухмодальность g_final посчитана по гистограмме, объединяющей все ρ и оба протокола; основной довод в пользу двух режимов — путь-зависимость внутри окна (при D = on доля низкого режима 6,5–14 % в протоколе A против 93–100 % в B). Расхождение pilot и main по ρ_release (0,383 против 0,368) не объяснено: длина перегрузки даёт только около 0,004. Одна модель, один сервис; один триггер, выбранный на опорной ячейке (Δ меняется на ±0,1); метастабильность конечного горизонта; зависимость от θ при D = on; метод оценки порога (разброс до 0,017); R2 ≈ R1 предопределено узким диапазоном пауз; R3 реализован скользящим окном; результат LIFO/ALIFO зависит от учёта просроченных записей в очереди (D-005, D-014); eLIBRARY и CyberLeninka не просмотрены.
