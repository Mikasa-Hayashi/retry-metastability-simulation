# Эксплораторные дозапуски (по замечаниям проверки К2, В2, В6, В9)

Все результаты ниже эксплораторные (вне препрегистрации). Данные: results/explor/ (seed 1400000–1475439, 75 440 задач, пропусков, дублей и ошибок нет, reports/run_log_explor.md); база для сравнения: results/raw (только чтение). Скрипты: analysis/explor_*.py; таблицы: results/analysis/explor_*.csv; графики: figures/F16–F21 (png, svg, csv). Bootstrap B = 2000, ДИ отражают только выборочную ошибку.

## 1. Зависимость от горизонта восстановления H_rec (К2)
Три ячейки, R = 40, H_rec ∈ {1500, 3000, 6000, 12000, 24000}. Таблицы explor_k2_*.csv, рисунок F16 и далее.
- **R1/FIFO/off/Exp.** ρ_release: 0,335 → 0,351 → 0,368 → 0,384 → 0,400. Приращение за удвоение H постоянно (0,0159; 0,0168; 0,0159; 0,0159), наклон +0,0162 [0,0150; 0,0175], R² = 0,9999. Насыщения нет, дрейф логарифмический. Δ падает с 0,528 до 0,457 (около −0,018 за удвоение H).
- **R2/FIFO/on/Exp.** Δ 0,298 → 0,215, наклон −0,021 за удвоение H, без затухания.
- **R1/FIFO/on/LogN.** Δ: 0,062 → 0,032 → 0,010 → 0,004 [−0,003; 0,011] → −0,003 [−0,010; 0,004]. Окно закрывается при H ≳ 10⁴ (логарифмическая экстраполяция около 1,5·10⁴), ρ_fold и ρ_release сходятся к ≈ 0,80.
- **H3 как функция H.** Отклонение sim − MF для R1/FIFO/off/Exp: 0,058; 0,074; 0,091; 0,107 [0,103; 0,111]; 0,123 [0,119; 0,127]. Критерий |sim − MF| ≤ 0,10 нарушается между 6000 и 12000, оценка H* = 9050 [8380; 9830]. Прогноз по первым трём точкам совпал с наблюдением.
- **Механизм (эксплораторно).** Время жизни отказа после перегрузки конечно (Каплан–Майер, протокол B, H = 24000), ln τ линеен по ρ с наклоном 41,2 [36,2; 46,9]. Это предсказывает сдвиг порога 0,0168 [0,0148; 0,0191] за удвоение H против наблюдённых 0,0162. Для Exp-ячеек согласуется, для LogN/on предсказание завышено (0,032 против 0,011). Оценка по 3–5 точкам ρ и экспоненциальной модели, строгой проверкой не является.
- **Вывод.** Наблюдаемая «область бистабильности» при конечных K и c является долгоживущей метастабильностью: Δ и ρ_release зависят от горизонта H и не сходятся к пределу. Корректно писать «Δ при горизонте H» и приводить Δ(H). Утверждение H3 «подтверждена» верно только для H ≤ 6000.

## 2. Сильные триггеры для «нулевых» ячеек (В2)
12 ячеек (R3/FIFO × D × S ∈ {Exp, LogN}; LIFO, ALIFO с R1 × D × S ∈ {Exp, LogN}; Pareto исключён), триггеры (3; 50) и (4; 100), протокол A, R = 40. Гистерезиса (Δ ≥ 0,1) нет ни у одной ячейки. LIFO и ALIFO: P_A = 0 на всей сетке. R3/on: ρ_fold > 1,0. R3/off: срыв около 0,96 без удержания (Δ от −0,005 до +0,004). Отрицательный результат не является артефактом слабого триггера (таблицы explor_trg*.csv).

## 3. Параметры R2 и R3 (В6)
Протокол A, основной триггер; протокол B для вариантов не запускался, поэтому ρ_release вариантов не измерен: Δ* = ρ_fold(вариант) − ρ_release(база) — допущение, надёжны только ρ_fold и L_A.
- R2 (retry.base 0,5 и 2,0 против 1,0): сдвиги ρ_fold в [−0,013; +0,012], L_A в [−0,011; +0,011]. Вывод R2 ≈ R1 сохраняется. Ограничение: диапазон пауз узкий (0,5–2,0 при T = 10), паузы порядка T не проверялись.
- R3 (бюджет 0,05 и 0,20 против 0,10): изменения ρ_fold не более 0,013. По сравнению с R2 во всех 18 сочетаниях R3 даёт ρ_fold выше на 0,084–0,191 и L_A ниже на 0,084–0,155 (ДИ не включают 0). Метастабильности у R3 нет ни при одном бюджете.

## 4. Длина перегрузки в протоколе B (В9)
Значения 400 / 1000 / 2000 на 12 активных ячейках при H_rec = 1500. ρ_release сдвигается не более чем на 0,012; значимы 2 из 24 сдвигов (R1/off/LogN и R1/off/Pareto при 400). R1/off/Exp: Δ = 0,532 / 0,528 / 0,532. Расхождение pilot и main в ρ_release (0,383 против 0,368) длиной перегрузки не объясняется.

## 5. Что меняется в выводах
- В тексте «область бистабильности» заменить на «область гистерезиса конечного горизонта»; Δ сообщать вместе с H и таблицей Δ(H).
- H3 «подтверждена» при H ≤ 6000 и была бы отвергнута при H ≥ 12000; теория занижает ρ_release на 0,058–0,123.
- H1′ верна на горизонте 1500; для LogN/on окно закрывается при H ≳ 10⁴.
- Устойчивы отрицательные результаты по LIFO, ALIFO, R3 (к силе триггера), R2 ≈ R1 (к паузам 0,5–2,0), независимость от длины перегрузки. Формулировать «в данной модели и параметрах».

## 6. Ограничения
Три ячейки по H_rec; Δ не оценивается там, где ρ_fold цензурирован; экстраполяции на большие H — порядок величины, не прогноз; протокол B для вариантов R2 и R3 не запускался.
