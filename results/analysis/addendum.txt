## 1. К1: определение отказа и бимодальность g_final (эксплораторно)
Метод: g_final каждого прогона основной сетки (ρ ≤ 1, 5000 прогонов на ячейку, протоколы A и B вместе); бимодальность: отношение плотности в провале к меньшему из двух пиков (valley_ratio, сглаженная гистограмма, шаг 0,025), смесь двух нормалей (Ashman D, D > 2 — режимы разделены), доля g_final в [0,3; 0,7]. Пакета для критерия Хартигана нет, вместо него смесь и отношение провала.

Что показано (табл. X1, рис. F14):
- Все 12 активных ячеек двухмодальны: valley_ratio 0,000–0,013, Ashman D 8,9–33,5. Версия «бимодальности нет» данными не подтверждается.
- Что верно в К1: при D = on режим отказа не лежит в нуле. Он расположен при g ≈ 0,2–0,5 (Exp; пик около 0,24 у R1 и 0,21 у R2) и 0,3–0,6 (LogN; пик 0,39 и 0,36), с хвостом до 0,6. Большая доля g_final в [0,3; 0,7] — это сам режим отказа, а не «промежуточное состояние»: A/B = 0,004/0,298 (R1/on/Exp), 0,359/0,434 (R1/on/LogN), 0,001/0,230 и 0,262/0,417 (R2). При D = off: 0,000–0,015. Провал между режимами (g ≈ 0,6–0,9) не пуст: 1–10 прогонов на столбец против 10²–10³ в пиках.
- По 72 ячейкам (табл. X2) выше 0,02 доля [0,3; 0,7] у 4 ячеек D = on (R1, R2 / FIFO / Exp, LogN), у R3/FIFO/off (0,02–0,11, срыв около ρ ≈ 0,96 без гистерезиса) и R0/FIFO/off (LogN, Pareto) на уровне 0,02–0,03.

Чувствительность Δ к θ (пересчёт g_final, R = 100; табл. X3, рис. F15; θ = 0,5 воспроизводит T01 с точностью 1e-16):
- D = off и Pareto/on: Δ не зависит от θ (разброс по θ не больше 0,003).
- R1/on/Exp: 0,129 / 0,272 / 0,276 (θ = 0,3 / 0,5 / 0,7); R2/on/Exp: 0,213 / 0,300 / 0,303.
- R1/on/LogN: 0 / 0,060 / 0,080; R2/on/LogN: 0 / 0,088 / 0,096.
- Причина падения при θ = 0,3: порог лежит внутри режима отказа (пик 0,2–0,4), часть отказавших прогонов классифицируется как здоровая; при LogN режим отказа выше 0,3 целиком. Это зависимость от положения θ относительно режима отказа, а не отсутствие двух режимов. θ = 0,5 для LogN/on тоже слегка занижает Δ (хвост режима отказа до 0,6): 0,060 против 0,080 при θ = 0,7.
- Вне 12 ячеек при θ = 0,3 и 0,7 новых активных нет (максимум Δ по остальным 60: 0,005; файл t41c).

Мера по разрыву, без θ (табл. X5, X6): отказ = g_final ниже порога-долины ячейки (середина плато минимальной плотности между пиками). Δ_gap: R1/on/Exp 0,276 [0,272; 0,282], R1/on/LogN 0,081 [0,075; 0,087], R2/on/Exp 0,304, R2/on/LogN 0,096; ячейки D = off и Pareto совпадают с θ = 0,5 в пределах 0,005. Путь-зависимость внутри окна (ρ_release_gap; ρ_fold_gap): в низком режиме 6,5–14 % прогонов A и 93–100 % прогонов B при D = on (при D = off: B 68–98 %).
H1′ на Δ_gap: r(Exp) = 0,545, r(LogN) = 0,244, разность 0,300 [0,287; 0,314] (T42b). По θ: 0,323 [0,303; 0,337] (0,3), 0,333 [0,320; 0,346] (0,5, план), 0,300 [0,287; 0,314] (0,7) (T41b). Знак и размер эффекта сохраняются при любом определении отказа, ДИ не содержит 0. Ограничение: порог-долина выбран по тем же данным, ДИ только выборочные и неопределённость выбора порога не учитывают. Оговорка К1 остаётся: при D = on режим отказа близок к θ, абсолютная Δ при D = on определена менее надёжно, чем при D = off; r(LogN) приводить как интервал по определениям отказа (0,205 при θ = 0,5; 0,244 по долине; 0,243 при θ = 0,7; 0 при θ = 0,3).

## 4. В9: порог по плану и по интерполяции (табл. M1–M3)
12 активных ячеек: логистика (план), изотоника, линейная интерполяция сырых P. Макс. расхождения с планом: ρ_fold 0,007 (изотоника) и 0,017 (интерполяция), ρ_release 0,015, Δ 0,015 и 0,014. Интерполяция вне 95 % ДИ плана у 11 из 24 порогов: ДИ отражают только выборочную ошибку при логистической модели и уже различий между методами (до 0,015–0,017).
Эффекты по трём методам: D on − off −0,215 / −0,219 / −0,215; R2 − R1 +0,011 / +0,008 / +0,005 (разброс между методами сравним с эффектом: писать «около нуля, не более 0,02»); разность H1′ 0,333 / 0,354 / 0,350.
R2/FIFO/on/Exp: ρ_fold = 0,867 (логистика), 0,874 (изотоника), 0,875 (интерполяция). Сырые P_A (n = 100): 0,32 (0,84), 0,40 (0,85), 0,43 (0,86), 0,40 (0,87), 0,61 (0,88), 0,69 (0,89). Кривая замедляется на 0,85–0,87 (≈ 0,41 по 300 прогонам) и затем скачет до 0,61; симметричная логистика по всей кривой даёт P = 0,5 при 0,867, где наблюдается 0,40 (около 3,5 стандартных ошибок по трём точкам). Пересечение 0,5 лежит между 0,87 и 0,88, поэтому локальные методы дают 0,874–0,875. Это асимметрия формы кривой, а не шум. Различия порогов менее 0,03 не интерпретировать.

## 7. Итог по H1′
Подтверждающий результат не меняется: r(Exp) − r(LogN) = 0,333 [0,320; 0,346]. Диагностика К1 частично подтверждает критику (положение θ при D = on решает судьбу LogN/on: при θ = 0,3 эффекта нет, при θ ≥ 0,5 есть), но опровергает «нет бимодальности»: два режима разделены во всех 12 ячейках. H1′ формулировать как «остающаяся при передаче срока доля Δ зависит от S», с интервалом r(LogN) 0,20–0,24 при θ ≥ 0,5 и по разрыву, и оговоркой о θ = 0,3.
