# Препрегистрация (черновик, замораживается на G3)

Статус: ЗАМОРОЖЕНО тегом `prereg-v1` (24.10.2026, гейт G3; автор поручил принять рекомендации по итогам pilot). Изменения после тега только отдельным разделом «Отклонения» с датой и причиной.

История до заморозки: формулировки H1′, H2′, критерий отказа при ρ > 1 и метрики-спутники введены ПОСЛЕ просмотра pilot (seed 0–162799), не основного прогона; в статье это сообщается. Исходные H1, H2 сохранены и будут отчитаны как вырожденные (pilot: reports/pilot.md).

## Вопрос
Как фактор R (политика повторов), Q (дисциплина очереди), D (крайний срок), S (распределение времени обслуживания) влияют на ширину области бистабильности Δ = ρ_fold − ρ_release (определение: MODEL_SPEC §6)?

## Гипотезы
**H1 (устойчивость рейтинга).** Рейтинг конфигураций (R×Q×D) по Δ при экспоненциальном обслуживании не совпадает с рейтингом при тяжёлых хвостах (LogN cv = 2).
- Мера: коэффициент Кендалла τ между векторами Δ для S = Exp и S = LogN по 18 конфигурациям R×Q×D (R ∈ {R1,R2,R3}, Q ∈ {FIFO,LIFO,ALIFO}, D ∈ {off,on}; в первой редакции ошибочно было «24»; вместе с R0 — 24, сообщается дополнительно).
- H1 отвергается, если нижняя граница 95 % bootstrap-ДИ для τ ≥ 0,8.

**H1′ (влияние S на эффект D; подтверждающая).** На 12 активных ячейках (R1,R2 × FIFO × D × S) относительное остаточное Δ при D = on к D = off, r(S) = Δ_on/Δ_off, различается между S = Exp и S = LogN.
- Мера: разность r(Exp) − r(LogN) с bootstrap-ДИ по репликам (R1 и R2 усредняются). H1′ подтверждается, если ДИ не содержит 0. Описательно: τ-b по L_A (потеря goodput) по 24 конфигурациям с ДИ и τ-b по Δ с долей связок.

**H2 (комбинация).** Комбинация R3 (бюджет повторов) и Q = ALIFO уменьшает Δ сильнее, чем каждая из мер по отдельности.
- Мера: контраст взаимодействия на Δ по факторам (R3 vs R2) × (ALIFO vs FIFO), при D и S усреднённых и отдельно по S.
- H2 подтверждается, если ДИ контраста лежит ниже 0 (эффект сильнее суммы эффектов) при S = Exp и сохраняется по знаку при LogN.

**H2′ (R3 против R2 на непрерывных метриках; подтверждающая).** Внутри Q = ALIFO и отдельно внутри Q = FIFO R3 уменьшает потерю goodput L_A относительно R2 не менее чем на 0,01.
- Мера: L_A(R3) − L_A(R2) по протоколу A, ρ ≤ 1, при D и S усреднённых и отдельно по S, bootstrap-ДИ по репликам. Эффект практически значим при верхней границе ДИ ≤ −0,01. Вторично: усиление и wasted. По pilot внутри ALIFO эффект около нуля, то есть H2′ там вероятно не подтвердится; это допустимый результат.

**H3 (точность аналитики).** Для R1, Q = FIFO, D = off mean-field модель (THEORY.md, конечное K) предсказывает ρ_release с отклонением от симуляции не более 0,10 при S = Exp. Для LogN (cv = 2) и Pareto теория неприменима (замкнута только для Exp): разность сообщается описательно, порог не назначается.
- Мера: |ρ_release^theory − ρ_release^sim| с ДИ. Порог δ = 0,10 зафиксирован на G3 по pilot (≈ 36 % от MF-значения 0,277; pilot-отклонение +0,055 при H_rec = 1500 и +0,106 при H_rec = 6000, поэтому отклонение сообщается при каждом H_rec).
- H3b (верхняя граница). Симуляционный ρ_fold (протокол A, граница бассейна притяжения при заданном триггере) не превышает mean-field ρ_fold^MF (исчезновение здоровой ветви). Мера: ρ_fold^sim − ρ_fold^MF с ДИ; H3b отвергается, если нижняя граница ДИ > 0.
- Примечание (изменено 22.10.2026 до заморозки, см. DECISIONS.md D-001): ρ_fold протокола A не равен mean-field складке и зависит от силы триггера. Прямое сравнение этих величин как «точности» некорректно, поэтому точность проверяется по ρ_release, а для ρ_fold проверяется только граница.

Допустимы результаты «не подтвердилось». Они публикуются.

## План анализа
1. Оценка ρ_fold, ρ_release, Δ по каждой конфигурации (MODEL_SPEC §6), ДИ bootstrap.
2. Контроль R0: Δ ≈ 0 (иначе, ошибка модели).
3. Факторный анализ: по 72 конфигурациям сообщается классификация (N1: нижняя граница ДИ Δ > 0; N2: точечное Δ ≥ Δ_min и ρ_fold < 1). Регрессия Δ на R, Q, D, S и их взаимодействия (OLS с весами, обратными дисперсии bootstrap) строится только по активным ячейкам (N1, по pilot 12); у остальных оба порога цензурированы, дисперсия bootstrap равна 0 и веса не определены, они описываются таблицей и непрерывными метриками (L_A, L_B, H, wasted, усиление, время восстановления). Устранение метастабильности (Δ = 0) — самостоятельный результат. Отчёт — размеры эффектов с ДИ. Парные сравнения: поправка Холма.
4. Эффект по рангам: Cliff's delta и бутстреп-различия Δ для ключевых пар.
5. Чувствительность: θ ∈ {0,3; 0,5; 0,7}; T ∈ {5; 10; 20}; K ∈ {64; 128; 256}; H_rec ∈ {1500; 3000; 6000} (измеренный ρ_release зависит от окна восстановления); сила триггера ×0,5 и ×1,5 (одна переменная за раз, на подмножестве из 12 активных ячеек: R ∈ {R1,R2} × FIFO × D ∈ {off,on} × S ∈ {Exp,LogN,Pareto}).
6. Время восстановления: кривые выживаемости (Каплан–Мейер, цензура горизонтом) по политике.
7. Все p-значения, если приводятся, — после поправки; основной упор на ДИ и размеры эффекта.

## Параметры, зафиксированные на G3
c = 8, K = 128, T = 10, θ = 0,5, D_s = 25, множитель триггера m_s = 1,5, окна W / H_rec / последнее окно = 100 / 1500 / 300, длина перегрузки в протоколе B = 1000 при ρ = 1,05 (D-017), bootstrap B = 2000, Δ_min = 0,1, θ_q (ALIFO) = 0,5.

Сетка ρ: грубая 0,20; 0,25; …; 1,00 (17 точек) для протоколов A и B; один раунд уточнения шагом 0,01 в окне ±0,05 вокруг каждого нецензурированного порога. Вспомогательная область перегрузки: 1,05; 1,1; 1,2; …; 2,5 (только для Δ_ext).

Реплики: R = 40 на все 72 конфигурации; R = 100 на 12 активных ячеек; R = 16 в области ρ > 1; R = 40 на чувствительность. Правило эскалации: ячейка вне 12 активных с точечным Δ ≥ 0,1 и ρ_fold < 1 на грубой сетке при R = 40 дозапускается до R = 100.

Seed'ы: основной прогон от 1 000 000, уникальный seed на задачу (общие случайные числа не используются, D-018).

Критерий отказа: g_final < θ при ρ ≤ 1; при ρ > 1 (вспомогательная область) g_final < θ·min(1, 1/ρ). Основная метрика Δ(ρ ≤ 1). Метрики-спутники: L_A, L_B = ∫(min(1,1/ρ) − g)dρ по [0,2; 1,0], H = ∫|g_B − g_A|dρ, wasted, усиление, время восстановления (с долей цензурированных).

Ограничения: единый триггер выбран на опорной ячейке, Δ зависит от него (0,42–0,59 при m_s 1,75–1,25 на pilot) и это сообщается в чувствительности. Условие допустимости K/c > T эксплораторно.

## Правило калибровки триггера (только на pilot, seeds 0–999999)
Триггер (множитель m_s, длительность D_s) один для всех конфигураций основной сетки. Выбирается на pilot для опорной конфигурации R1, Q = FIFO, D = off, S = Exp: из заранее заданной сетки m_s ∈ {1,5; 2; 3; 4} × D_s ∈ {25; 50; 100} (порядок по (m_s − 1)·D_s, CALIBRATION_PLAN.md) берётся самый слабый триггер, при котором Δ ≥ 0,1 и ρ_fold < 1. Если такого нет, подбираются T и K (в пределах диапазонов чувствительности) и решение фиксируется в DECISIONS.md. После G3 триггер не меняется. Контроль R0 (Δ ≈ 0) проверяется при выбранном триггере.

## Критерии исключения прогонов
Только технические сбои (исключение процесса, нарушение инвариантов V4). Каждое исключение логируется. Исключать «неудобные» результаты запрещено.

## Отклонения (после тега prereg-v1)
Раздел заведён 24.10.2026 по замечаниям независимой проверки (внутренней проверки). Текст выше не менялся.
1. **H1, два вердикта.** Правило отвержения «нижняя граница 95 % ДИ τ ≥ 0,8» в плане не уточняло, какой ДИ брать. В анализе приведены оба: bootstrap по ячейкам (нижняя граница 0,884) и по репликам (0,627). По первому правилу H1 формально отвергнута, по второму нет; из-за 14 вырожденных ячеек из 18 ни один вердикт не содержателен. Оба сообщаются.
2. **Происхождение H1′, H2′, порога δ = 0,10 и критерия при ρ > 1.** Введены после просмотра данных pilot (seed < 1 000 000), до основного прогона. В статье они описываются как сформулированные после pilot.
3. **Δ_ext (область ρ > 1)** вспомогательная и эксплораторная; результат N1_ext = 13 (R3/FIFO/on/LogN, Δ_ext = 0,040 [0,001; 0,078]) не считается подтверждённым: грубая сетка и R = 16.
4. **Семейство для поправки Холма** (24 парных сравнения) определено при анализе.
5. **Решающее правило H3** — по верхней границе ДИ модуля отклонения ≤ 0,10.
6. **Эксплораторные дозапуски** по замечаниям проверки (H_rec = 12 000 и 24 000, сильные триггеры, параметры R2 и R3, длина перегрузки B) выполнены отдельно, в results/explor/, не входят в подтверждающий анализ и помечены эксплораторными.
